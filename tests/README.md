# Проверка нативного JavaScript

`npm test` проверяет отсутствие jQuery и безопасный запуск без компонентов.

Браузерные регрессии используют настоящие DOM API, анимации, Swiper и noUiSlider:

1. Из корня проекта запустить `python -m http.server 4174 --bind 127.0.0.1`.
2. Открыть `http://127.0.0.1:4174/tests/browser.html`.
3. Дождаться результата в заголовке вкладки и списка PASS/FAIL.
4. Открыть `http://127.0.0.1:4174/tests/mobile.html`: тесты запускаются во фреймах шириной 390px и 1440px; рядом доступна мобильная главная страница.

Отправка заявок в тестах перехватывается подменой `fetch`: реальные запросы форм не выполняются.
