# Bort

## Форматирование исходников

- `npm run format` — форматирование `src/js/app.js`, самописных модулей JavaScript и SCSS.
- `npm run format:check` — проверка тех же файлов без изменения содержимого.

После изменений JS/SCSS запускайте форматирование, а перед завершением задачи — проверку.
Библиотеки, собранные файлы в `docs` и генерируемые SCSS шрифтов и иконок исключены.
HTML не входит в команды форматирования.

Prettier отвечает за оформление кода. Явные блоки с фигурными скобками для условий
и циклов, а также пустые строки между смысловыми частями проверяются при написании
и ревью. Алгоритмы и порядок CSS-правил при форматировании сохраняются.
