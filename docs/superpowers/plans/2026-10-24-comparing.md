# Страница сравнения

Основа: шесть макетов Figma из задания. Используем существующие compare.html,
comparing.scss и шаблон карточки; сохраняем Gulp, include/loop и Swiper.

1. Обновить существующую разметку: заголовок, категории, карточки, важные и общие характеристики.
2. Настроить mobile-first стили: две независимые колонки до 1200px, общий слайдер и названия параметров слева на ПК.
3. Реализовать компактную закреплённую панель, фильтры, важные параметры и удаление.
4. Собрать HTML/SCSS/JS без очистки docs. Проверить 375/768/1440px, прокрутку и действия.

Макеты показывают противоречащие друг другу названия и цены одного товара на разных экранах.
Используем единые данные карточек из основного макета ПК. Демо-данные заполнены для
измельчителей. Дополнительные категории показывают пустое состояние; их данные
не предоставлены. По умолчанию показываем все строки, чтобы выбранный фильтр
соответствовал видимым данным (в макетах выбран фильтр различий, но видны одинаковые строки).
